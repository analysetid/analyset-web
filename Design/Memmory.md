# Design — Memmory

## Keterangan Isi Folder
Folder berisi **acuan design yang WAJIB diikuti** saat membuat design website Analyset.

**Isi (2 hal):**
1. `Brand Guideline.pdf` — panduan design (logo, warna, tipografi, dll.) yang menjadi acuan wajib.
2. `Logo/` — file logo milik Analyset yang boleh digunakan dalam design website:
   - Analyset - Logo.png
   - Analyset - Logo & Brand.png
   - Analyset - Brand.png
   - Analyset - Logo 1.png
   - Analyset-icon.png

## Aturan / Instruksi yang Harus Diikuti
1. Semua design website Analyset **WAJIB mengikuti Brand Guideline** di folder ini.
2. Logo yang digunakan wajib dari folder `Logo/` ini.
3. Baca `Memmory.md` parent (`../Memmory.md`) sebelum bekerja.
4. Sebelum diserahkan ke agent eksekutor/OpenCode, Brand Guideline PDF perlu diekstrak jadi nilai presisi (hex color, nama font) ke file terpisah (mis. `brand-tokens.md` / `tailwind.config.js`) agar konsisten dipakai di kode.
5. Konflik aturan parent vs child → konfirmasi ke user.
