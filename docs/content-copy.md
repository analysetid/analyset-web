**Header:** "Layanan Kami" — "Empat lini layanan yang dirancang untuk membantu korporat menengah mengoptimalkan data mereka."

### 1. Pembuatan Model Machine Learning *(layanan andalan)*
"Kami merancang dan membangun model machine learning yang disesuaikan dengan tantangan bisnis spesifik Anda — dari prediksi risiko keuangan hingga deteksi anomali transaksi."
- Model prediktif untuk pengambilan keputusan bisnis
- Deteksi anomali & fraud pada data keuangan

- Evaluasi dan tuning model berkelanjutan

### 2. Implementasi Data Analytics
"Kami membantu perusahaan membangun sistem analitik yang mengubah data operasional menjadi dashboard dan laporan yang actionable."
- Dashboard bisnis real-time
- Analisis tren keuangan & operasional
- Konsolidasi data dari berbagai sumber
- Rekomendasi berbasis data untuk manajemen

### 3. Automation
"Kami mengotomatisasi proses kerja repetitif yang memakan waktu tim Anda — seperti rekonsiliasi, pelaporan, dan input data manual."
- Automasi rekonsiliasi keuangan
- Automasi pelaporan berkala
- Integrasi antar sistem/aplikasi
- Pengurangan human error pada proses manual

### 4. Pengembangan Aplikasi
"Kami membangun aplikasi custom yang mendukung kebutuhan operasional dan analitik bisnis Anda."
- Aplikasi internal untuk tim operasional/keuangan

- Aplikasi berbasis web, sesuai kebutuhan spesifik klien

## Case Study (halaman detail)

**Header:** "Studi Kasus" — "Bukti nyata bagaimana Analyset membantu bisnis mengoptimalkan proses melalui data."

### Kopi Kenangan — Automation Rekonsiliasi Keuangan

**Problem:**
"Kopi Kenangan menghadapi tantangan proses rekonsiliasi keuangan manual yang memakan waktu tim finance secara signifikan setiap minggunya, meningkatkan risiko human error dan menghambat efisiensi operasional."

**Solution:**
"Analyset merancang dan mengimplementasikan sistem automation rekonsiliasi yang mengotomatisasi proses pencocokan data transaksi, menggantikan pekerjaan manual berulang dengan alur kerja otomatis."

**Result:**
"Implementasi automation ini berhasil menghemat **100 jam kerja per minggu** tim finance Kopi Kenangan — waktu yang sebelumnya dihabiskan untuk rekonsiliasi manual kini dapat dialokasikan untuk pekerjaan yang lebih strategis."

## About

**Header:** "Tentang Analyset"

**Overview** *(adaptasi dari Brand Guideline PDF overview, Bahasa Indonesia)*:
"Pertumbuhan teknologi informasi yang sangat pesat membuat data — baik milik institusi, perusahaan, maupun individu — menjadi semakin kompleks dan masif. Fenomena Big Data pun berkembang pesat, dan keberadaan data kini menjadi krusial dalam pengambilan keputusan bisnis yang tepat.

Analyset hadir untuk menjawab tantangan ini. Kami membantu mengubah data Anda menjadi panduan nyata bagi aktivitas bisnis, termasuk dalam pengambilan keputusan strategis. Visi kami adalah menjadi solusi data satu pintu (*one-stop data solution*) yang mempermudah aktivitas bisnis Anda — melalui proses pengumpulan, analisis, dan rekomendasi solusi berbasis data yang Anda miliki."
