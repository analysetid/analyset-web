# Docs — Memmory

## Keterangan Isi Folder
Folder berisi **seluruh instruksi pembuatan website Analyset**. Bersama folder `Design/`, ini adalah bahan utama yang dipakai untuk membangun website.

**Isi:**
- `PRD.md` — brief utama (tujuan, scope, requirements, constraints, open questions)
- `sitemap.md` — struktur halaman & section per halaman
- `brand-tokens.md` — warna, font, logo (nilai presisi dari Brand Guideline PDF)
- `design-system.md` — komponen Tailwind reusable (button, card, navbar, footer, form)
- `content-copy.md` — teks final siap-pakai per section
- `seo-spec.md` — keyword, meta tags, schema.org, technical SEO
- `acceptance-criteria.md` — checklist QA sebelum halaman dianggap selesai

## Aturan / Instruksi yang Harus Diikuti
1. Baca `Memmory.md` parent (`../Memmory.md`) sebelum bekerja.
2. Seluruh dokumen di folder ini **WAJIB dibaca** sebelum membangun/mengubah website.
3. Copy teks WAJIB dari `content-copy.md`; warna/font dari `brand-tokens.md`; komponen dari `design-system.md`.
4. Konflik aturan parent vs child → konfirmasi ke user.
